# 确定性基线优先（0.0.15 提炼，批 D）

**原则**：先用最简单可解释的确定性模型建立可复现基线，再叠加复杂性。基线是后续所有改进的对照锚点。

**何时加载**：所有题型的 Modeler/Coder 初始规划阶段。

**执行清单**：
- 线性/确定性问题：先用 LP/精确求解器得出基线解，记录最优目标值与约束违反量 `max_violation ≤ 1e-6`。
- 预测问题：先用线性回归/均值预测建立 `R²/MAE` 基线，再引入 XGBoost/随机森林。
- 仿真问题：先用固定种子单次确定性运行，再引入 Monte Carlo。

**门禁**：`expected_artifacts` 必须包含基线结果表（含来源标注 题目原文/数据统计/文献标准），`acceptance_metrics` 至少有一项 `baseline_objective` 与 `advanced_objective` 的对比，禁止直接以复杂模型结果作为唯一证据。

   GPU 违反 2 格）→ LNS 后 1,450,393,813 CNY（**−0.07% 负优化**），GPU 违反恶化到 242 格。
   根因：MILP 目标只用电价代理成本，无 GPU 容量约束（1000 行等式仅"每任务选一区"），解天然
   倾向堆积低价区，破坏容量可行。v2 版之所以有 GPU 行，是因为它的 MILP 带 GPU 约束行。

   实际可达最优。93-95 分路线的"任务级 LNS/MILP"在算力预算内无正向收益，正式终结。
   论文维持 88-90 分全绿交付态（TECHNICAL_PASS 12/12、五件哈希 MATCH、主 work_dir 未被触碰）。

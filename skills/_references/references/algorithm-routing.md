# 算法路由速查

先用本表确定当前子问题的主路线，再按引用位置读取
`../math_modeling_norms.md` 的**对应章节**；不要一次加载整份模型目录。

| 题目输出/约束 | 主路线 | 按需读取的规范章节 | 先做的验证 |
| --- | --- | --- | --- |
| 在约束下最大化、最小化或分配资源 | 优化 | 模型大分类与选型速查；优化类模型详细指南 | 可行性、单位、边界和基线解 |
| 预测未来数值或时间序列 | 预测 | 模型大分类与选型速查；预测类模型详细指南 | 时间切分、误差指标、物理边界 |
| 多方案评分、排序或效率比较 | 评价 | 模型大分类与选型速查；评价类模型详细指南 | 指标方向、标准化、权重和一致性 |
| 路径、网络、匹配或流量 | 图论/网络 | 图论与网络类模型 | 有向性、容量/守恒、子回路 |
| 分类、聚类、相关性或统计推断 | 统计/机器学习 | 统计分析与机器学习 | 划分方式、泄漏、指标与样本量 |
| 系统随时间或空间演化 | 机理/动力学 | 机理/动力学类模型 | 初边值、量纲、守恒与步长收敛 |
| 多种输出混合 | 分层组合 | 先读主路线，再读必要的子路线 | 每一层的输入输出和接口一致性 |

## 使用规则

1. 在 `ANALYSIS_MODELING_REPORT.md` 中为每个子问题记录：题型、主路线、一个可解释基线、候选方法、输入可用性和验证口径。
2. 数据不足时优先选择与样本量和题面信息匹配的简化模型；不要以复杂模型替代缺失证据。
3. 将最终候选交给 `2a-method-validation` 做 PoC 和人工选型；本路由不替代人工决定，也不构成算法效果证明。
